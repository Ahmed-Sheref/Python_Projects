# 📂 PDF Tools Repository

This repository contains various tools and utilities for working with PDF files. The project aims to provide efficient ways to manipulate, edit, and process PDFs using automation.

## 📁 Folder Structure
- **PDF_tools/** - Contains scripts and tools for handling PDFs.

## 🚀 Features
- Merge multiple PDFs into one.
- Split a PDF into multiple files.
- Extract text from PDFs.
- Convert PDFs to images.
- Encrypt and decrypt PDFs.
- Compress PDFs to reduce file size.

## 🛠 Technologies Used
- Python (PyPDF2, PDFMiner, ReportLab)
- Bash scripts (for automation)
- C++ (for performance-heavy tasks)
